    <h2>⚙️ Installation & Setup</h2>

    <pre><code>

    </code></pre>

    <p>Move into the project folder:</p>

    <pre><code>
cd ASSAM-TEA
    </code></pre>

    <p>Install dependencies:</p>

    <pre><code>
npm install
    </code></pre>

    <p>Start the server:</p>

    <pre><code>
node server.js
    </code></pre>
