ASSAM TEA — Cinematic Website

A cinematic and immersive storytelling website inspired by the beauty, culture, and atmosphere of Assam Tea plantations. Built using AI-assisted vibecoding workflows, creative visuals, smooth animations, and optimized media experiences.
The project focuses on creating a visually engaging web experience with cinematic transitions, storytelling elements, and media-rich interactions while maintaining smooth performance and responsiveness.

Live Demo : https://assamtea.netlify.app/

Installation & Setup

Clone the repository: git clone https: //github.com/SayanMallick55/ASSAM-TEA.git
Move into the project folder: cd ASSAM-TEA
Install dependencies: npm install
Start the server: node server.js


Deployment 

This project is deployed using Netlify.
Steps:
Push the repository to GitHub
Connect GitHub repository to Netlify
Deploy the website
